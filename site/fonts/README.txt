Fonts served from this site so that visitors' browsers never contact a font provider.
All three are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org):
- Fraunces, by Undercase Type (https://github.com/undercasetype/Fraunces)
- Atkinson Hyperlegible, by the Braille Institute (https://www.brailleinstitute.org/freefont/)
- IBM Plex Mono, by IBM (https://github.com/IBM/plex)
Only the Latin subset is included.
